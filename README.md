# Brown Dwarf Spectra On-Ramp

Jupyter notebooks that teach undergraduates to connect the shape of a brown dwarf spectrum
(0.75–5 µm, SPHEREx resolution) to molecular absorption and to the global parameters of model grids.
They are the on-ramp to the separate candidate-review job (out of scope here).

Students run everything in **Google Colab** from this public repository and install nothing. The same
notebooks run locally in Jupyter.

## Order of use

| # | Notebook | Big idea | Needs |
|---|---|---|---|
| 0 | [Getting started](notebooks/00_getting_started.ipynb) | run cells, save a copy, read a plot | references |
| 1 | [Blackbodies and brightness temperature](notebooks/01_blackbodies.ipynb) | a spectrum can be read as temperatures | references |
| 2 | [Opacity and the photosphere](notebooks/02_opacity_photosphere.ipynb) | bands show higher, cooler layers | toy library |
| 3 | [The band atlas](notebooks/03_band_atlas.ipynb) | which absorber shapes which part | toy, references |
| 4 | [The spectral sequence](notebooks/04_spectral_sequence.ipynb) | L0 → Y4 | references |
| 5 | [Global atmospheric parameters](notebooks/05_global_parameters.ipynb) | what each grid parameter does | model library; low-g/low-Z references |
| 6 | [Fitting models to spectra](notebooks/06_fitting_models.ipynb) | model-grid fits to the references, χ² maps, comparing with the named template, indices, data problems | references, fitting grid |

Students keep the [field guide](field_guide/README.md) open while working.

## Repository layout

```
notebooks/      00–06, generated by scripts/build_notebooks.py (edit the script, not the .ipynb)
field_guide/    Markdown pages; img/ is generated by scripts/build_field_guide_figures.py
bdtools/        helper package students call (loading, units, Planck, binning, comparison, indices, plots)
data/
  references/   reference spectra + catalog.csv          (scripts/build_reference_library.py)
  models/       curated model subset + catalog.csv       (scripts/build_model_library.py, plan in library_plan.yaml)
                fit_grid_diamondback.npz: full grid for notebook 6 fits (scripts/build_fit_grid.py)
  toy/          precomputed toy-model outputs (.npz)     (scripts/build_toy_library.py)
  indices.yaml  index definitions (Rustamkulov et al. 2026 Table 5) — instructor-editable
  bands.yaml    band atlas used by every plot and the field guide — instructor-editable
scripts/        everything that builds data or notebooks
tests/          tests for bdtools
```

All spectra use one format: CSV with `# key: value` header lines recording units and provenance
(see `bdtools/io.py`). Toy outputs are `.npz` (documented in `data/toy/README.md`).

## Instructor: rebuilding everything

Use any Python ≥ 3.10 with numpy, scipy, matplotlib, pandas, pyyaml (all preinstalled in Colab);
building also needs h5py, nbformat and nbclient. From the repository root:

```bash
python tests/test_bdtools.py                         # or: pytest tests/
python scripts/build_toy_library.py                  # seconds
python scripts/build_reference_library.py           # reads ../data/SPIFF_library_files (SPIFF Zenodo zips)
python scripts/build_model_library.py --check        # which planned grid points exist
python scripts/build_model_library.py                # after setting approved: true in library_plan.yaml
python scripts/build_fit_grid.py                     # all 1440 Diamondback models for notebook 6 (slow on OneDrive)
python scripts/build_field_guide_figures.py
python scripts/build_notebooks.py --execute         # writes + runs all notebooks
```

`--execute` runs every notebook top to bottom and fails loudly if any cell errors. To preview a model
library built elsewhere without copying it in, set `BDTOOLS_MODEL_DIR` (or `BDTOOLS_REFERENCE_DIR`).

**Questions for the instructor**

Resolved (2026-11-16):

- Indices are computed on F<sub>ν</sub> in Jy.
- Index uncertainty: the paper's quadrature formula, with each region's σ<sub>F</sub> = √Σσ<sub>i</sub>²/N (see `data/indices.yaml`).
- Index planes plot one index against another; axes are never combined (`bd.plot_index_plane(seq, x=, y=)`).
- The SPIFF binned spectra are the reference spectra.
- Flame Skimmer (which has a K<sub>zz</sub> axis) is now the late-T/Y grid; its K<sub>zz</sub> sweep is in notebook 5.
- Channel widths (2026-11-17): taken from SPIFF's own channel table, which defines the binned channels. The SPHEREx
  calibration files (`data/SPHERExSpectralFiles_202607`) describe the native instrument channels, which the
  notebooks do not use.
- Missing Table 1 objects (2026-11-17): use the next-best object of the same type (L9, Y1); ~Y4 has none.

Still open:

1. *Exo-REM gravity units:* `list_gridpoints_cloudyfsed_2026.txt` labels g as m s⁻², with values 10³–10⁵, while the
   file names say `logg3.0`–`logg5.0`. Read as cm s⁻², these are log g = 3.0–5.0, the usual brown-dwarf range, and
   match the file names. Read as m s⁻², they would be log g (cgs) = 5–7, i.e. 100–10,000 times Earth's gravity,
   above what even the most massive brown dwarfs reach (log g ≈ 5.5). So the header label looks like a typo; cgs assumed.
2. *Spec wording:* the spec says “late-T and Y dwarfs” lie wholly short of the Planck peak; by Wien's law that holds
   below ~580 K (Y and the very latest T). Notebook 1 says so explicitly.
