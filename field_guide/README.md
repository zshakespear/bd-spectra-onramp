# Field guide

Keep this open while you work. The notebooks teach; the guide reminds. Each page fits on about
one screen and links back to the notebook section that explains it.

| Page | Use it when… |
|---|---|
| [Reading a spectrum in five steps](reading_a_spectrum.md) | you meet any new spectrum |
| [Band atlas](band_atlas.md) | you want to know which absorber shapes a wavelength range |
| [Spectral sequence cheat sheet](spectral_sequence.md) | you want to know what a spectral type looks like |
| [Global parameters](parameters/README.md) — [T<sub>eff</sub>](parameters/teff.md) · [log g](parameters/gravity.md) · [[M/H]](parameters/metallicity.md) · [clouds](parameters/clouds.md) · [mixing](parameters/mixing.md) | you are explaining why a spectrum differs from its best-fit model or template |
| [Reading a model fit](model_fits.md) | you look at a best fit, its residuals, or a χ² map |
| [Indices](indices.md) | you compute or compare the CH<sub>4</sub>, CO<sub>2</sub>, CO indices |
| [Spotting data problems](data_problems.md) | **always, before you interpret a feature** |
| [Glossary](glossary.md) | a word is unfamiliar |
